# NAFNet Restoration Plug-in

A GIMP 3.2+ filter plug-in for NAFNet image restoration. The
sidecar architecture mirrors the
[CloudyTabzy/Gimp-lama-inpainting](https://github.com/CloudyTabzy/Gimp-lama-inpainting)
plug-in: the GIMP side is pure stdlib + `gi`/`Gimp`/`GimpUi`/`Gegl`,
the ML worker (Rust by default, Python fallback) runs in a
separate process that talks ORT CPU. Two filters are exposed:

- `plug-in-nafnet-restore` — restore the entire active drawable
- `plug-in-nafnet-restore-region` — restore only the selected
  region (uses a 64 px context ring so the model has surrounding
  pixels to inform the restoration)

The model is `NAFNet-REDS-width64_v1.onnx` (275 MB) from
[HuggingFace deepghs/image_restoration](https://huggingface.co/deepghs/image_restoration).
NAFNet is a 2022 image-restoration architecture by Megvii; this
REDS variant is trained for general image restoration (deblurring
+ mild denoising). It is **1:1 spatial** (input H,W == output H,W)
and processes only RGB (alpha is dropped).

---

## What it does

| Filter | Input | Output | Use when |
|---|---|---|---|
| Restore Image (NAFNet)... | Active drawable | Restored drawable | Whole-image deblurring; you want the model to see the full photo |
| Restore Selection (NAFNet)... | Active drawable + selection | Restored pixels inside selection; outside unchanged | Targeted restoration; faster on big images because the worker only processes the bbox |

For a 1024×1024 image, the Rust worker takes ~9 s on CPU. 4K
images are tiled with 512×512 tiles and a 32 px overlap, blended
in the overlap region with a 2D tent window so seams are not
visible. Smaller images run as a single inference (no tiling
overhead).

## Install

```cmd
cd nafnet-restoration-py
install.bat
```

The installer:

1. Detects GIMP 3's bundled Python 3.14.
2. Detects (or accepts a path to) a system Python 3.10+ for the worker.
3. Installs `pillow`, `numpy`, `onnxruntime` into the worker Python if missing.
4. Writes per-user `.interp` files mapping the `#!nafnet-gimp-python`
   shebang to GIMP's Python. (Never touches the GIMP install.)
5. Downloads `NAFNet-REDS-width64_v1.onnx` from HuggingFace into
   the source dir (~275 MB; skipped if already present).
6. Copies plug-in files to `%APPDATA%\GIMP\3.2\plug-ins\nafnet-restore\`.
7. If `cargo` is on PATH, builds the Rust worker and copies it next
   to the Python worker. The Rust worker is the default when present.

Restart GIMP. The filters appear under `Filters > Enhance > Restore Image (NAFNet)...` and `Filters > Enhance > Restore Selection (NAFNet)...`.

## Build (Rust worker, optional)

The Python worker is the default. The Rust worker is an opt-in
faster-cold-start replacement.

```cmd
cd nafnet-worker-rs
cargo build --release
```

Output: `target/release/nafnet-worker.exe`. The install script
copies it to the plug-in dir as `nafnet-worker_rust.exe` and the
plug-in will prefer it.

## Architecture

Same sidecar pattern as the LaMa plug-in:

```
GIMP process  (MINGW Python 3.14, gi + GEGL only)
  └─ #!nafnet-gimp-python  (shebang → user-level .interp mapping)
       └─ nafnet-restore.py
            ├─ exports drawable (+ optional selection ROI) to temp PNG(s)
            ├─ spawns nafnet-worker_rust.exe (default) or nafnet_worker.py
            └─ loads result PNG into drawable shadow buffer, merge_shadow
                    │
                    ▼
           worker process  (Rust or Python, with Pillow + onnxruntime)
               onnxruntime / ort CPU provider
               ?? model pipeline: load PNG -> HWC f32 [0, 1] -> (Rust:
                  tile + blend overlap; Python: single forward) -> NAFNet
                  -> HWC f32 -> save PNG
```

Rust worker CLI:

```
nafnet-worker.exe --image input.png --output result.png --model model.onnx
                  [--tile-size 512] [--tile-overlap 32]
```

Python worker CLI (identical contract):

```
python nafnet_worker.py --image input.png --output result.png --model model.onnx
```

Both write `[LAMA_MARKER] phase <name>` lines to stderr for the
GIMP parent to log progress.

## Worker selection

Precedence (first match wins):

1. `NAFNET_USE_RUST_WORKER=1` (opt in) or `0` (opt out)
2. `worker_kind` field in `nafnet_config.json` (`"rust"` or `"python"`)
3. Default: Rust worker when binary exists, Python otherwise

The installer sets `worker_kind: rust` automatically when the Rust
worker is present.

## Test

Cross-project tests live in `tests/`:

```cmd
cd tests
python test_worker_rust.py
python test_worker_python.py
python test_workers_consistency.py
```

Each test creates a synthetic image, runs a worker, and verifies
the output. The consistency test runs the same input through both
workers and asserts the outputs match within tolerance
(max abs diff < 5% on a 256×256 input).
